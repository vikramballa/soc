# MITRE ATT&CK data

`enterprise-attack-compact.json` is derived from the official MITRE ATT&CK® STIX 2.1 bundle
(<https://github.com/mitre-attack/attack-stix-data>) by `scripts/build_mitre_dataset.py`.
It keeps IDs, names, tactics, platforms, URLs and shortened descriptions.
